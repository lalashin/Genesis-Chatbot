## 형태를 고른 이유 (dataviz 가이드: 형태 먼저, 색은 나중)
| 보여줄 것 | 형태 | 이유 |
|---|---|---|
| 동작 구조 | 순서도 | 비개발자에게 "무엇이 어떤 순서로" 일어나는지가 핵심 |
| 개발 과정 | 3단계 흐름 + 표 | 단계 수가 적고 "문제 → 해결" 문장이 핵심이라 차트보다 표가 읽기 쉬움 |
| 개선 효과 | **숫자 타일 (차트 아님)** | 단위가 제각각(개수, %, 초, 회)이라 한 차트에 넣으면 축이 섞임. 전후 차이가 메시지라 숫자+변화량이 가장 빠르게 읽힘 |

## 문제와 해결
- **물결표가 취소선으로 보임**: 타일 문구 "-1~2회 (개선 전 2~3회)"의 `~` 두 개가 마크다운 취소선으로 해석 → 대시(–)로 변경
- **브라우저 캡처 멈춤**: 팝업을 연 탭에서 화면 캡처가 30초 시간 초과. 페이지 자체는 정상(SVG 20개, 오류 없음)이라 새 탭에서 다시 열어 확인
