## 문제와 해결

### 1. "한도 초과 시 라이브러리가 몰래 재시도해서 느린 것"이라는 가설 → 아님
- 기본값 `max_retries=6`을 보고 의심했지만, 라이브러리 코드를 따라가 보니 임베딩은 재시도 옵션을 SDK에 넘기지 않아 재시도 없음, 답변 모델은 우리가 `max_retries=1`로 둠
- **배운 점**: 그럴듯한 가설도 코드나 측정으로 확인하기 전에는 원인이라고 말하지 않는다

### 2. `thinking_budget=0` → 400 INVALID_ARGUMENT
- 생각하기 단계를 끄려고 넣었는데 Gemini 3.x flash-lite는 거부
- 실제 호출로 비교: 기본 / `thinking_level=minimal` / `low` 모두 동작, 차이는 1초 이내 → `minimal` 채택

### 3. 답변이 "핵심 답:"으로 시작
- 프롬프트 "핵심 답을 첫 문장에 먼저 말하세요"를 머리말로 그대로 출력 → "첫 문장에서 바로 답하고 머리말을 붙이지 말라"로 수정

### 4. 이어지는 질문
- Agent는 모델이 검색어를 다시 썼지만 체인은 질문을 그대로 검색 → "그럼 냉각수는?"만으로는 엉뚱한 페이지
- 짧거나 '그럼/그건…'으로 시작하면 직전 질문과 합쳐 검색 → 23쪽(추천 오일 및 용량) 찾고 정답 확인
