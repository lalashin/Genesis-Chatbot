## 문제와 해결

### 1. 2차원 "뜻 지도"가 제목과 다른 그림을 보여 줌
- **계획**: 768차원을 2차원으로 압축(PCA)한 산점도에서 같은 주제의 질문과 조각이 모이는 모습
- **실제**: 질문끼리, 조각끼리 따로 모임. 주제가 아니라 "질문이냐 문서냐"로 나뉨
- **원인**: Gemini는 질문용(RETRIEVAL_QUERY)과 문서용(RETRIEVAL_DOCUMENT) 임베딩을 다르게 만든다 → 가장 큰 차이(첫 번째 축)가 "종류"가 됨. 768차원 그대로는 6개 모두 정답 주제가 가장 가까웠음
- **해결**: 압축 그림 대신 **압축하지 않은 실제 유사도 히트맵**으로 변경
- **배운 점**: 시각화가 메시지와 다르게 보이면 그림을 고치는 게 아니라 **데이터를 정직하게 보여 주는 형태**로 바꾼다. 차원 축소 그림은 "대략적인 모습"일 뿐 근거가 될 수 없다

### 2. 색 검증 (dataviz 가이드)
- 히트맵은 크기(유사도)를 나타내므로 한 색상의 밝기 단계(순차 팔레트) 사용
- 검증 도구 결과: 가장 어두운 단계 `#104281`이 다크 배경(#141414)과 대비 1.86:1로 기준(2:1) 미달 → 한 단계 밝은 `#1c5cab`부터 시작하도록 바꿔 **전 항목 통과**

### 3. 세로축 질문 이름표가 잘림
- 긴 질문이 "바퀴에 바람은 얼…"처럼 잘림 → 축에는 번호 붙인 짧은 이름표, 전체 문장은 마우스를 올리면 툴팁과 캡션에 표시

### 4. 브라우저 화면 캡처 도구가 반복해서 시간 초과
- 페이지 자체는 정상(화면 갱신 1ms, 차트·표 렌더링, 오류 없음)인데 팝업에 차트가 있으면 캡처가 30초 시간 초과되는 일이 잦았음 → 최종 화면 확인은 사용자에게 요청
