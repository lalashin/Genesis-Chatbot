## 문제와 해결

### 1. 보고서 초안의 사실 오류 (report-generator 에이전트)
- **증상**: 검증 기준 92.9%, "flake8 통과", 단계 구분이 커밋 이력과 다름, 히트맵을 "1,005조각 비교"로 설명, 이미 끝난 모바일 테스트를 "다음 단계"로 기재
- **원인**: 요약 자료만 보고 빈칸을 그럴듯하게 채움. flake8은 **한 번도 실행한 적이 없음**
- **해결**: 근거 기준으로 재계산(24/28 = 85.7%, 받아쓰기 지연 미측정·부분 구현 3건 제외), 린트는 "실행하지 않음"으로, 단계는 커밋 이력대로 수정
- **배운 점**: AI가 쓴 보고서도 **숫자와 "통과"라는 표현은 근거를 하나씩 대조**한다

### 2. "2번 해줘"를 잘못 해석
- **증상**: 사용자는 표의 ②(README 링크 한 줄)를 원했는데, 마지막 선택지 2번(README + 앱 팝업 링크)으로 해석해 push까지 함
- **원인**: 한 답변 안에 번호 목록이 두 개(표의 ①~④, 마지막 질문 1~3)라 "2번"이 애매했음
- **해결**: 기록을 지우지 않고 되돌리는 커밋(`b9535b77`)으로 README 한 줄만 남김
- **배운 점**: 선택지는 번호 체계를 하나만 쓰고, 애매하면 실행 전에 확인. 범위가 다르면 작은 쪽이 기본
