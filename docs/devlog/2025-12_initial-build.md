## 돌아보며 발견한 문제 (2026-10 점검 결과)

당시에는 화면상 잘 동작했지만, 나중에 점검하면서 아래 문제들이 발견되었습니다.
**"AI가 만든 코드는 겉보기에 동작해도 검증이 필요하다"**는 교육 사례로 쓸 수 있습니다.

| 문제 | 영향 | 원인 |
|---|---|---|
| 문서 분할 구분자가 `"\\n"` (문자 `\` + `n`) | 문단/줄 단위로 나뉘지 않고 글자 수로만 잘림 | 코드가 문자열로 한 번 더 감싸진 채 붙여넣어진 것으로 추정 |
| `requirements.txt`가 UTF-16 인코딩 | 배포 환경에 따라 패키지 설치 실패 가능 | Windows PowerShell 리다이렉션(`pip freeze >`)의 기본 인코딩 |
| `venv/` 폴더(2만여 개 파일)가 git에 커밋됨 | 저장소 용량 증가 (팩 175MB) | `.gitignore` 추가 전에 커밋 |
| `.env`(API 키)가 한 번 커밋 후 삭제됨 | 키가 이력에 남음 → 키 폐기로 대응 | `.gitignore`를 나중에 추가 (`3310179c`) |
| 음성 인식 핸들러가 rerun 후 동작 안 함 | 오버레이가 안 닫히고 취소 불가 | 아래 2026-10 일지 참고 |
| 디버그 파일, 백업 파일이 저장소에 남음 | 구조 파악이 어려움 | 시행착오 파일을 정리하지 않음 |

## 배운 점
- 배포 전 체크리스트(인코딩, `.gitignore`, 비밀값)를 먼저 만들었다면 대부분 막을 수 있었다.
- 기능을 추가할 때마다 기록(무엇을, 왜)을 남기지 않아, 나중에 이유를 복원하기 어려웠다.
