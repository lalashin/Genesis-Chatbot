# 기획서: GENESIS AI Assistant 데모 고도화

- **작성일**: 2026-10-07
- **브랜치**: `10-demo-upgrade`
- **상태**: 초안 — ⚠️ 표시는 작성자(Claude)의 가정이므로 확인이 필요합니다

## 1. 문제 정의

교육 과정 초기에 AI 채팅만으로 만든 챗봇을 **실습용 데모이자 교육 자료**로 쓰려고 한다.
현재 버전은 동작은 하지만 시연과 교육에 쓰기에 다음 문제가 있다.

| 문제 | 시연·교육에 주는 영향 |
|---|---|
| 음성 인식이 차량 용어를 틀리게 알아들음 ("차체" → "자체") | 시연 중 엉뚱한 답변 |
| 음성 코드가 Streamlit 내부 구조에 의존 (부모 페이지 DOM 조작) | 버전이 바뀌면 다시 깨질 위험 |
| 답변의 근거(매뉴얼 페이지)가 보이지 않음 | RAG의 핵심인 "근거 있는 답변"을 보여줄 수 없음 |
| 답변이 다 만들어질 때까지 빈 화면 | 기다리는 시간이 길게 느껴짐 |
| 한도 초과 등 오류가 영어 원문으로 노출 | 시연 중 당황 |
| 검색 품질을 수치로 말할 수 없음 | "잘 된다"를 증명할 근거 없음 |
| 734줄 단일 파일, CSS 해킹 다수 | 교육 자료로 코드를 설명하기 어려움 |

## 2. 사용자와 시나리오

| 사용자 | 시나리오 |
|---|---|
| **시연자(강사)** | 수업/발표에서 음성·텍스트로 질문하고 근거와 함께 답변을 보여준다 |
| **수강생** | 단계별 코드(git 태그)와 기록(docs)을 보며 RAG 챗봇 제작 과정을 따라 한다 |
| ⚠️ 일반 방문자 | 배포 링크로 접속해 써 본다 (PC·모바일) |

## 3. 기능 범위

| 단계 | 기능 | 우선순위 |
|---|---|---|
| 2 | 검색 품질 평가 세트(질문 20개 + 정답 페이지)와 측정 스크립트 | 필수 |
| 3 | 음성 입력을 `st.audio_input` + Gemini 받아쓰기로 교체, 차량 용어 힌트, 받아쓴 문장 확인 후 전송 | 필수 |
| 4 | 답변 출처(매뉴얼 페이지) 표시, 스트리밍 출력, 예시 질문 버튼 | 필수 |
| 5 | 한도 초과(429)·모델 오류의 친절한 안내, 패키지 버전 고정 | 필수 |
| 6 | 코드 분리(앱/에이전트/음성/스타일), 불필요한 CSS 정리 | 권장 |
| 7 | 평가 세트로 재측정, 개선 전후 비교 | 필수 |
| 8 | 배포 확인, README·교육 자료 정리 | 필수 |

**범위 밖**: 로그인, 사용자별 대화 저장, 다른 차종 매뉴얼 추가, 유료 모델 사용

## 4. 성공 기준

| 기준 | 목표 | 측정 방법 |
|---|---|---|
| 검색 정확도 | 평가 세트에서 정답 페이지가 상위 검색 결과에 포함되는 비율(Hit@k) ⚠️ **80% 이상** | `eval/run_eval.py` |
| 음성 인식 | 차량 용어가 포함된 질문 ⚠️ 10개 중 8개 이상 정확히 받아쓰기 | 아침 실사용 테스트 |
| 출처 표시 | 검색을 거친 답변에 페이지 번호 표시 | 화면 확인 |
| 오류 처리 | 429 발생 시 한국어 안내 문구, 앱이 멈추지 않음 | 강제 오류 테스트 |
| 배포 | PC·모바일에서 텍스트·음성 질문 동작 | 배포 링크 확인 |

## 6. 위험과 대응

| 위험 | 대응 |
|---|---|
| 무료 한도 초과 | 질문당 호출 수 최소화, 429 안내, 필요 시 프로젝트 분리 |
| Gemini 모델 지원 종료 | 모델 이름을 설정 한 곳에서 관리, 실제 호출로 확인 |
| 받아쓰기 지연(녹음 → 업로드 → 변환) | 받아쓰기는 가벼운 모델 사용, 처리 중 표시 |
| UX 변화(자동 감지 → 녹음 버튼) | 받아쓴 문장 확인 단계로 오인식을 시연 중에 바로잡을 수 있게 |

## 7. ⚠️ 확인이 필요한 가정
1. 음성 비서 **온보딩 토글**은 `st.audio_input`에서는 마이크 권한을 브라우저가 녹음 시 직접 묻기 때문에 필요가 줄어든다. → 토글을 "음성 입력 표시/숨김" 용도로 바꿨다. 기존처럼 유지하길 원하면 알려 주세요.
2. 받아쓴 문장은 **바로 전송하지 않고 확인 후 전송**한다 (시연 안정성 우선). 바로 전송을 원하면 설정 한 줄로 바꿀 수 있게 한다.
3. 성공 기준의 목표치(80%, 10개 중 8개)는 임의로 정한 값이다.
