# 프로젝트 기록 (docs)

이 폴더는 GENESIS AI Assistant의 **제작 과정 기록**입니다.
실습용 데모이자 교육 자료로 쓰기 위해, 무엇을 만들었는지뿐 아니라
**왜 그렇게 했는지, 어떤 문제를 겪고 어떻게 풀었는지**를 남깁니다.

## 구성

| 폴더/파일 | 내용 | 언제 쓰나 |
|---|---|---|
| [`../CHANGELOG.md`](../CHANGELOG.md) | 단계별 변경 요약 (사용자 관점) | 단계를 마칠 때마다 |
| [`plan/`](plan/) | 기획서 (문제 정의, 기능, 성공 기준) | 고도화를 시작할 때 |
| [`devlog/`](devlog/) | 개발 일지: 한 일, **문제와 해결**, 다음 할 일 | 작업한 날마다 |
| [`decisions/`](decisions/) | 결정 기록: 선택지, 고른 것, **이유** | 중요한 기술 선택을 할 때 |
| [`eval/`](eval/) | 검색 품질 평가 세트와 결과 | 데이터/검색을 바꿀 때 |
| [`lessons/`](lessons/) | 교육용 차시 자료 | 단계가 끝나 정리할 때 |
| [`templates/`](templates/) | 위 문서들의 작성 틀 | 새 문서를 만들 때 |

## 기록 규칙

1. **커밋 메시지**: `NN-작업내용` (예: `10-음성 입력을 st.audio_input으로 교체`)
2. **브랜치**: 단계별 작업은 `NN-주제` 브랜치에서 하고 확인 후 master에 병합
3. **태그**: 단계가 끝나면 `vN-이름` 태그 (수강생이 단계별 코드를 받아볼 수 있게)
4. **문제는 숨기지 않는다**: 실패한 시도와 오류 메시지도 devlog에 남긴다 (가장 좋은 교육 소재)
