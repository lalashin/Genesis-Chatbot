## 8. Match Rate

- **구현 여부 기준**: (15 + 10 + 3×0.5) / 28 = **94.6%** (엄격 기준 25/28 = 89.3%)
- **검증 완료 기준**: 15 / 28 = **53.6%** (외부 요인 해소 시 24/28 = 85.7%)

**권장 순서**: G1·G4 즉시 처리 → 한도 초기화 후 25청크·벡터 검색 평가 → 실제 마이크·모바일 테스트 → 배포 확인 → G2·G3·G5·G10 → 가정 A1~A3 사용자 확인.
