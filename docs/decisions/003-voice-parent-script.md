# 003. 음성 인식 로직을 부모 페이지에 스크립트로 설치

- **날짜**: 2026-10-07
- **상태**: 대체됨 → [004](004-voice-audio-input.md)

## 배경
음성 인식(Web Speech API) 코드는 `components.html` iframe 안에서 실행되며 부모 페이지 DOM을 조작했다.
Streamlit rerun마다 iframe이 새로 만들어지면서, iframe에서 등록한 핸들러가 실행되지 않아
오버레이가 닫히지 않고 취소 버튼이 동작하지 않았다.

## 선택지
| 선택지 | 장점 | 단점 |
|---|---|---|
| **부모 페이지에 `<script>`로 1회 설치** | 기존 UX 유지, 빠른 수정 | 여전히 Streamlit 내부 구조에 의존 |
| `st.audio_input` + 서버 받아쓰기 | 안정적, 정확도 개선 가능 | 사용 방식 변경(녹음 버튼) |

## 결정
당장의 버그는 부모 페이지 설치 방식으로 고쳤다 (`40f20ddb`).

## 이유
배포 중인 데모의 버그를 빠르게 막기 위해 UX를 유지하는 쪽을 먼저 택했다.

## 영향
- 버그는 해결되었으나 인식 정확도("차체" → "자체") 문제가 남았다.
- 근본 개선은 [004](004-voice-audio-input.md)에서 진행.
